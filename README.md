# Inbox Janitor

A Freeware Lab experiment.

Inbox Janitor is a friendly Gmail cleanup and analysis utility designed to make it easy to understand what is filling up your inbox before deleting anything.

## First goal

Version 0.1 will:

- Connect to Gmail using Google's OAuth flow
- Start in read-only mode
- Analyze mailbox contents
- Identify large messages and attachments
- Show frequent senders
- Show old/promotional mail
- Estimate cleanup opportunities
- Delete absolutely nothing

## Freeware Lab Principles

1. Make it fun.
2. Make it easy.
3. Make it useful.
4. Make it safe.
5. Make it understandable.

## Status

Very early experiment.

No Gmail account access has been implemented yet.
